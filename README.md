**Transform an idea into a complete implementation with zero manual coordination!**

2. **Wait** for automated plan generation (2 minutes)  
3. **Approve** the plan with a comment
4. **Watch** as all issues are created and agents start work automatically
5. **Review** PRs as they're opened

**That's it!** The system handles:
- ✅ Comprehensive planning

## 🚀 Quick Start

### 🏷️ Labels Setup (First Time Only)

Before using the orchestrator, ensure labels are set up:

```bash
# Automatic (via GitHub Actions)
gh workflow run setup-labels.yml --repo garantor/ai-dev-team

# Or manual (via script)
./scripts/setup-labels.sh
```

View all labels: [github.com/garantor/ai-dev-team/labels](https://github.com/garantor/ai-dev-team/labels)

See the [Labels Guide](docs/LABELS.md) for details on each label.

### Automated Orchestration (Recommended)

**Submit your idea and let automation handle the rest:**

```bash
# Using the CLI script
./scripts/orchestrate.sh

# Or create an issue directly
# Go to Issues → New Issue → "🚀 AI Orchestrator" template
```

**What happens next (automatically):**
1. ✅ Plan generated by AI (1-2 minutes)
2. ✅ You review and approve
3. ✅ All issues created with dependencies (1-2 minutes)
4. ✅ Agents start working automatically
5. ✅ Daily progress reports
6. ✅ Dependencies resolved as work completes

[📖 **Full automation guide →**](docs/AUTOMATION.md)

### Manual Development Workflow

**For direct development without orchestration:**

1. **Create a Feature** - Use issue templates in [Issues](../../issues/new/choose)
2. **Assign to Agent** - Label with appropriate agent tag (`backend`, `frontend`, etc.)
3. **Implement** - Agent creates PR following template
4. **Test** - QA Agent reviews and tests
5. **Deploy** - Merge when all checks pass

## 🤖 Automation Features

### 1. **AI Plan Generation**
- Automatically analyzes product ideas
- Generates comprehensive implementation plans
- Breaks down into P0/P1/P2 features
- Creates technical architecture
- Defines agent tasks with dependencies

### 2. **Automatic Issue Creation**  
- Parses approved plans
- Creates all agent issues automatically
- Sets up dependency chains
- Links issues to orchestrator
- Labels issues appropriately

### 3. **Agent Coordination**
- Triggers agents when dependencies are met
- Resolves blocked issues automatically
- Manages inter-agent communication
- Updates progress in real-time

### 4. **Progress Tracking**
- Daily automated progress reports
- Real-time status updates
- Completion percentage tracking
- Next actions identification

### 5. **CLI Script** (`scripts/orchestrate.sh`)
```bash
./scripts/orchestrate.sh

Options:
  1) Submit a new product idea
  2) Check orchestrator status
  3) Approve a plan
  4) Request plan revisions
  5) List all orchestrators
  6) View progress report
  7) Cancel an orchestrator
```

## ⚙️ Configuration

### For Automated Plan Generation

Add `OPENAI_API_KEY` to repository secrets:
1. Go to Settings → Secrets and variables → Actions
2. New repository secret
3. Name: `OPENAI_API_KEY`
4. Value: Your OpenAI API key

Without this, manual planning instructions will be provided.
